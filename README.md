# 🎵 Sonora Player

O **Sonora** é um player de música moderno, minimalista e de código aberto desenvolvido para proporcionar uma experiência fluida de streaming de áudio. Com uma interface Dark Mode refinada e focada no usuário, o projeto foi construído para demonstrar habilidades avançadas de front-end, consumo de dados assíncronos e gerenciamento de estado.

---

## ✨ Funcionalidades Principais

### 🚀 Reprodutor & Streaming
* **Player Completo:** Controles nativos de reprodução incluindo pausar, pular, retroceder, modo aleatório (shuffle) e repetição.
* **Barra de Progresso Dinâmica:** Indicador visual do tempo corrido e duração total da faixa musical em execução.
* **Controle de Volume Integrado:** Ajuste rápido de ganho diretamente pela interface do usuário.

### 📊 Biblioteca & Histórico Visual
* **Painel de Estatísticas:** Exibição em tempo real do total de faixas na fila, tempo total de duração e quantidade de músicas reproduzidas.
* **Gráficos de Histórico:** Linha do tempo de reprodução estilizada com barras horizontais coloridas que categorizam as faixas por duração (*Faixa curta*, *Faixa média*, *Faixa longa*).

### 🔍 Descoberta Musical
* **Busca Global:** Barra de pesquisa rápida para localizar músicas, artistas ou álbuns instantaneamente.
* **Músicas Similares:** Algoritmo visual na barra lateral que sugere faixas correlacionadas com base no artista ou gênero atual para manter o fluxo musical ativo.

## 🚀 Como Executar o Projeto

### Pré-requisitos
Antes de começar, você vai precisar ter instalado em sua máquina o [Node.js](https://nodejs.org) e um gerenciador de pacotes como o **npm**, **yarn** ou **pnpm**.

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd sonora
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   # ou
   yarn install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   # ou
   yarn dev
   ```

5. Abra o navegador em `http://localhost:3000` para ver o Sonora rodando.
